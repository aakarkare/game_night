# Party Game Hub

An interactive, browser-based game night application built for 4–5 players. 
The Host runs the main TV display, while guests use smartphones for Trivia submissions and view real-time results on a dedicated Questionnaire page.

## Active Features
- **Jeopardy:** Host-driven interactive board managed directly from the main TV display.
- **Trivia:** Live question presentation on TV with phone-based text submission and Host grading.
- **Questionnaire:** Dedicated full-screen hub (`/questionnaire`) displaying live Google Form polls and chart results.
- **Live Scoreboard:** Real-time session score management and host overrides.

## Tech Stack & Dev Environment

- **Backend & Realtime:** Firebase (Firestore, Realtime Database)
- **OS / IDE Target:** Linux (Ubuntu/Debian/Fedora) running VS Code
